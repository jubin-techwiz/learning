# Progress

Tracks the learner, not the topics: what has been completed, what is understood well, which gaps to revisit, and what to learn next. The learning coach reads these files at the start of a session ("continue", "next lesson") and updates them after each reviewed exercise.

This folder is **not** imported into Kenmora. The reference material lives in `../notes/`.

Several areas can be in progress at once. When you switch from one area to another, the area you leave is marked **Paused** in the roadmap and its file here records where to resume and what is still missing.

## Files

One file per area or series, named after it: `resilience.md`, `kafka.md`, `microservices.md`. A file is created only if you want progress kept for that subject.

## Format

```markdown
# Learning Progress Snapshot
- Subject:
- Goal:
- Completed:
- Strong areas:
- Gaps to revisit:
- Environment/setup:
- Last exercise and result:
- Next lesson:
```
